▸VERSION 0.3 — 20/04/2026

Version PowerApps 178 (3.26041.15)

Modifications

  • La création d'actions est + simple, mais nécessite une sauvegarde avant tout envoi dans la BDD
  • La page d'arrivée est désormais la page des CO-TQF-FM
  • Les éléments périmés apparaissent car le filtrage automatique engendrait des bugs
  • Suppression du bouton pour cacher/montrer l'onglet filtre sur CO-TQF-FM
  • Suppression du bouton import car désormais impossible de le faire selon la configuration actuelle
  • Quelques modifications de texte

Ajouts

  • Ajout des FM dans la base de données. Tous ce qui est CO-TQF est donc modifié en CO-TQF-FM ou CTF par gain de place
  • L'ajout d'une FM ce fait via l'élément vert. Le numéro se fait automatiquement selon le bâtiment et les éléments déjà existant
  • La montée d'indice d'une FM est selon le dernier indice du numéro de la FM. Il est impossible de monter l'indice A si le B existe
  • Dans la création d'action, il est possible de se mettre en pilote en cliquant sur la plume. Cela evite de chercher. Dispo dans d'autres onglet aussi
  • La numérotation des FM est identique avec celle des TQF : LBGN-2-AXI-FMO-xxyyyy-z
  • Le dernier import GED sur la BDD est désormais disponible dans l'onglet CO-TQF (idem que sur gestion des temps)
  • Un message de confirmation est désormais présent lorsqu'on quitte l'application
  • Il est désormais + simple de rechercher une typologie (CO, TQF et FM). Une liste de recherche est disponible
  • Il est possible de choisir des CO-TQF-FM en favoris
  • Il est possible de trier pour voir uniquement ces doc favoris
  • Le choix de favoris est possible lors de la création d'actions, pour CHR ou pour DOC
  • Les nouvelles CO-TQF se mettent automatiquement avec le commentaire "RAS"
  • Ajout d'un lien pour l'excel v2 (base de données complète v0.1) dans l'onglet CO-TQF-FM
