Liste des actions

  • GENERAL

  • Manually trigger a flow : Permet de lancer l'application. Permet aussi de récupérer le CSV de la GED pour analyse et traitement (input user)
  • ComposeTimeIn : Permet de récupérer l'heure du début du process. Sert a la fin pour calculer le temps d'éxécution du flow
  • GetItemsA02 : Permet d'avoir la liste des utilisateurs LABGENE
  • SelectA02 : Permet d'avoir un array type {gaia: nom}
  • JoinA02 : On prépare l'export au format JSON afin d'avoir un vrai dicitonnaire
  • ComposeA02json : On compose le dictionnaire JSON, permettant ainsi de faire des liens facile entre un numéro GAIA et un nom
  • ComposeCSV : Récupère les données du csv de la GED en un élément lisible pour power automate et le traitement de données
  • ComposeCSVTable : Transforme la ligne de données CSV en un tableau de 2 colonnes : l'ID et la grande ligne
  • ComposeHeader : Récupère les entêtes des colonnes
  • FilterArrayB01 : Permet d'avoir un tableau uniquement composé de document contractuels
  • SelectB01CSV : Permet de créer à l'échelle 1:1 les éléments présent dans B01, par simplicité.
  • FilterArrayB02 : Permet d'avoir uniquement les TQF et COR
  • SelectB02CSV : Permet de créer à l'échelle 1:1 les éléments présent dans B02, par simplicité.

  • RECUP BDD

  • GetItemsB01 : Permet de récupérer les élément de la BDD B01
  • SelectB01Quick : On fait une liste de type [] avec chaque tag complet de la BDD
  • SelectB01CSVQuick : On fait une liste de type [] avec chaque tag complet du CSV (donc traité au préalable avant)
  • FilterArrayPresentB01 : On check les élément du CSV non présent dans la BDD
  • SelectB01 : Permet de garder niquement l'ID et le tag afin de voir si celui-ci existe ou non en comparaison avec le CSV intégré
  • JoinB01 : Permet de joindre les éléments avec une, afin de faire un JSON
  • ComposeB01json : On le met au format JSON
  • FilterArrayB01New : On fait une query pour avoir les éléments non présent dans la BDD. Cela rend les "quick" obsolète. je garde pour le principe
  • ApplyToEachB01New : Loop sur chaque item nouveau du CSV non présentdans la BDD
    • CreateItemB01 : Créé le nouvel item dans la BDD B01
  • GetItemsB02 : Permet de récupérer les élément de la BDD B02
  • SelectB02 : Permet de garder niquement l'ID et le tag afin de voir si celui-ci existe ou non en comparaison avec le CSV intégré
  • JoinB02 : Permet de joindre les éléments avec une, afin de faire un JSON
  • ComposeB02json : On le met au format JSON
  • FilterArrayB02New : On fait une query pour avoir les éléments non présent dans la BDD
  • ApplyToEachB02New : Loop sur chaque item nouveau du CSV non présentdans la BDD
    • CreateItemB02 : Créé le nouvel item dans la BDD B02

  • TOUCHE FINALE

  • ComposeTimeOut : Permet de connaitre l'heure de la fin d'éxecution
  • ComposeComputeTime : Prend les valeurs d'entrée et sortie de temps afin de calculer le temps d'execution
  • CreateItemA08 : Permet de sauvegarder le fait qu'un flow a été lancé a un moment donné
  • SendAnEmailV2 : Envoi un email a l'utilisateur et a moi pour savoir qu'un flow a été lancé
