FONCTIONNEMENT

Le but de ce code est de générer des nomenclatures depuis les éléments de GESTIMA, ainsi que de générer des import GESTIMA depuis des nomenclatures générées depuis cette application. Pour cela, il faut :

  • Que ui.py et gestima_to_nm.py soient dans le même dossier
  • Que template_gestima.xlsx soit dans le dossier :\\d29.tes.local\NTE\AFFAIRES\NUC\T4R1A2601\12.QE\02_Outils\03_GESTIMA\999_-_Export_NM_GESTIMA. Si ce lien venait à changer (changement de nom de dossier ou de fichier), alors le code n'est pas fonctionnel
  • Le template_gestima.xlsx ne soit pas être modifié dans l'onglet "matrice_noms"
  • Des colonnes peuvent être ajoutés dans "matrice_noms", mais après celles existantes
  • Les critères spécifiques sont à rentrer à la suite dans l'onglet "matrice_noms" après les critères globaux
  • L'onglet "center" permet de dire ou non si les nomenclatures doivent centrer certains critères. Par défaut FALSE si non présent

PRE REQUIS

Il y a 2 étapes : installer python et installer les modules python nécessaires. (ETAPE 1) Il faut installer python via le portail d'entreprise (company portal) :

  • Chercher "Portail d'entreprise" dans la recherche windows
  • Dans la barre de recherche en haut, taper "python" et appuyer sur "Entrer"
  • Cliquer sur "Python 3.13 - Microsoft Stope App"
  • Cliquer sur "Installer"
  • L'installation prend entre 5 et 10 minutes (ETAPE 2) Il faut installer les modules via le fichier .bat
  • Aller dans le dossier \\d29.tes.local\NTE\AFFAIRES\NUC\T4R1A2601\12.QE\02_Outils\03_GESTIMA\999_-_Export_NM_GESTIMA\traitement_excel
  • Double cliquer sur "install_libraries.bat"
  • Cela installe les éléments nécessaire au traitement des données
  • Cela n'est PAS un virus, malgré une ouverture de l'invité de commande
  • Une fois terminé (environ 5 minutes max - le texte "Press any key to continue . . ." apparait), vous pouvez quitter l'invité de commande (soit la croix en haut à droite, soit en appuyant sur une touche du clavier, comme "A") L'application est désormais opérationelle.

UTILISATION

▸VERSION 0.4 — 22/04/2026

Modifications

  • Lorsqu'on choisi "ALL" dans les familles, cela exporte toutes les familles disponibles du ou des bâtiments choisies
  • Les familles non présentes mais coché (ou quand ALL est coché) sont mentionné dans un message d'erreur (fenetre + .txt)
  • Il y a désormais un excel par bâtiment, et non pas un excel par export
  • L'interface apparait en haut a gauche d'un écran plutot que au milieu. Cela evite que la fenetre soit coupée
  • Gestion des batiments et familles modifiés. Le batiment (building) est obligatoire dans le template GESTIMA
  • Le template GESTIMA a une colonne supplémenatire pour spécifier a quel équipement appartient la ligne dans le cas des critères spécifiques
  • Cette nouvelle ligne a apporté quelques bugs, mais ceux-ci sont désormais corrigés
  • [05/05/2026] Modification pour les numéros de salles. Il faut utiliser "_" et non "-" comme séparation. Le cas échéant, une date sera automatiquement rentrée dans le CSV...

Ajouts

  • Il est désormais possible de choisir un bâtiment. La liste est figée et devra être agrandie dans le temps
  • Il est possible de choisir "ALL" pour les bâtiment, permettant de choisir tous les bâtiments disponible dans la liste
  • Lorsqu'un bâtiment n'est pas présent dans l'excel de l'export, le fichier excel n'est pas généré pour ce batiment, et un message d'erreur apparait
  • Il est possible de montrer la PDG ou non. Le + simple est de ne pas la montrer car cela engendre quelques bugs
  • Après avoir chargé l'excel, il est possible de savoir ce qui est exportable par batiment en cliquant sur le bouton "Voir les données possibles"
  • Gestion des erreurs retravaillée
  • Un fichier .txt d'erreur apparait dans le dossier d'export si des erreurs ont été détécté (en + de la fenetre)
